Brief
Problem statement
The campus cafe keeps track of its products on paper. Build a console program that lets a staff member add products, see them, and answer simple questions about the stock. The program keeps showing a menu until the user chooses to exit.

Each product has a name (String), a price (double) and a quantity (int). Your program must:

Show a menu and keep running until the user chooses 0 (Exit).

Add a product, rejecting a price of 0 or less and a negative quantity with an error message.

Display all products, numbered from 1, or a message if there are none.

Calculate the total value of the stock (price × quantity for every product).

Calculate the average price, shown exactly and also rounded down.

Restock a product by its number, and duplicate a product using a copy constructor.

Count how many Product objects were created, using one static variable.

Learning objectives
Each part of the brief maps to a topic from class, so you can revise as you go.
